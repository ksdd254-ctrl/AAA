جدو الشايب تويك - خطوات الإطلاق
=================================

محتويات هذا المجلد
------------------
JdoTweak.exe       البرنامج (نسخة مربوطة بسيرفر تجريبي على جهازك: http://localhost:8080)
JDO_AutoFix.cmd    أداة الإصلاح التلقائي
server\            السيرفر: الحسابات، المفاتيح، الدفع، الإعلانات

اللي تم وتجرب
--------------
- البرنامج: 34 فحص للمحرك نجحت (التطبيق والإرجاع للقيمة الأصلية).
- السيرفر: 21 فحص نجحت (تسجيل + كود الإيميل، شراء، مفتاح، ربط بجهاز واحد،
  رفض جهاز ثاني، قفل وفتح، ريست الجهاز، وصول مجاني، إعلانات).
- حسابك كمالك جاهز: jdotweak@gmail.com (كلمة المرور محفوظة مشفرة فقط).

اللي لازم تسويه أنت قبل البيع
------------------------------
1) استضافة + دومين: سيرفر صغير (VPS) أو Render/Railway، ودومين باسمك.
   انسخ مجلد server هناك، وشغل:  npm install  ثم  npm start
2) انسخ الملف server\.env.example باسم .env واملأه:
   - BASE_URL = رابط موقعك
   - إيميل الإرسال (Gmail App Password)
   - مفاتيح Stripe للدفع (Apple Pay يطلع تلقائياً بعد توثيق الدومين في Stripe)
   - مفاتيح Cloudflare Turnstile لمنع البوتات
   شغّل السيرفر بالملف server\start-server.cmd (يعيد تشغيل نفسه لو وقف).
   في وضع الإنتاج (NODE_ENV=production) السيرفر يرفض يشتغل لو أي إعداد ناقص،
   ويطبع لك وش الناقص بالضبط.
   نسخة احتياطية من قاعدة البيانات تنحفظ كل يوم في server\data\backups (آخر 14 يوم).
3) أنشئ حسابك على السيرفر الحقيقي (مرة وحدة):
   OWNER_EMAIL=... OWNER_PASSWORD=... npm run seed-owner
4) ابني البرنامج النهائي برابط موقعك:
   powershell -ExecutionPolicy Bypass -File JdoTweak\build.ps1 -Api https://your-domain.com
   وحط الملف الناتج في server\files\JdoTweak.exe (هذا اللي ينزل للمشترين).
5) شهادة توقيع الكود (Code Signing) عشان ويندوز ما يحذر "ناشر غير معروف".
6) سجل الموقع في Google Search Console عشان يطلع بالبحث.
7) صفحات الموقع (الواجهة): السيرفر جاهز بكل الوظائف، لكن صفحات العرض
   تحتاج تنعمل (مطور ويب، أو متجر منتجات رقمية جاهز).

تنبيه مهم
---------
التويكات الـ 62 المختارة يدوياً مكتوبة بعناية. باقي المكتبة (~39 ألف) مأخوذة
من الباكات وما انجربت وحدة وحدة؛ جربها على جهاز تجربة قبل البيع.
